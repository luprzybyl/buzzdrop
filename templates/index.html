Zero-knowledge sharing for files and secret notes

Buzzdrop: file sharing that stings—just once.

BuzzDrop: secure, one-time file sharing. Upload encrypted files or secret notes, send a link, and let them vanish after a single successful view.

🔒Encrypted in the browser

AES-GCM + PBKDF2 protection happens before upload starts.

💥Self-destructing links

Shared files disappear after the first successful download or view.

📝Secret notes included

Send encrypted text notes when a file would be overkill.

Why Buzzdrop

One link. One view. Gone.

Perfect for contracts, credentials, handoffs, and anything else that should not linger in an inbox forever.

Your server never sees plaintext.

Encryption happens before upload, so Buzzdrop stores only ciphertext and metadata.

Built for flexible deployment.

Run it with local storage or S3, and tune file type and size rules for your team.

How it works

1. Encrypt before upload

Choose a file or write a note, set a password, and let the browser encrypt everything locally.

2. Share the generated link

Send the one-time link and share the password separately when you want the strongest protection.

3. Watch it self-destruct

After the first successful download or view, the encrypted payload is deleted automatically.
